# H2H 9-Cat for Sleeper — fan-built concept

A working prototype of **head-to-head category fantasy basketball** (redraft + dynasty), built by a long-time Sleeper user to show what the format could look like on Sleeper and to hand the team a head start.

> Unofficial. Not made by or affiliated with Sleeper. No Sleeper logos or assets are used.
>
> **Try it:** download [`dist/index.html`](dist/index.html) and open it in any browser — the whole demo is that one file.
> **License:** MIT — take whatever is useful.

## What's in here

| Path | What it is |
|---|---|
| `engine/` | Framework-agnostic ES modules: category scoring, lineup optimizer, z-score rankings + punt support, dynasty value, matchups, standings, playoffs, add/drop, taxi squads, trades (incl. future picks), draft logic. No DOM, no dependencies. |
| `tests/` | `node --test` suite (category ties, box-score consistency, schedule sanity, lineup optimizer, zero-sum standings, trade integrity, snake order, full season → champion). |
| `data/players.js` | 253 NBA players with real per-game lines (see Data). Generated by `scripts/build_players.py`. |
| `demo/` | The interactive demo UI (vanilla JS; `head.js` + `views2.js` + `tail.js` compose `app.js`) — matchup, team/lineup, players + punt builder, league/standings, trades, draft room, league chat, create-league wizard. |
| `dist/index.html` | The demo as one self-contained HTML file. Open it in a browser. |
| `docs/INTEGRATION.md` | How the engine maps onto a production stack. |

## Design

The demo UI follows the host app's existing web client: palette, type (Poppins / Inter / Lato), the 240px league sidebar, the rounded league panel with pill tabs (in the NBA orange accent), owner cards with win bars, mirrored starter rows, colored position badges and the League Chat event cards. The basketball league's web panels on the host currently read "not yet available for NBA fantasy" for Matchup, Team and Trade; this prototype is a working version of those three panels for categories leagues.

Two one-line hooks at the top of `demo/head.js` are left for the platform team:

- `BRAND.logo` — the brand logo asset (left empty in this fan build; no logos are included).
- `headshotUrl(p)` — licensed player headshots keyed by `p.sleeper_id`. Until set, players show a monogram avatar in their NBA team's colors.

## Run it

```bash
npm install          # esbuild only
npm test             # engine tests
npm run build        # -> dist/index.html
python3 scripts/build_players.py   # regenerate data/players.js from data/raw/*.csv
```

## Data: what's real and what's simulated

**Real**
- Per-game averages for 2025-26 (full season) and 2026-27 (season to date, ~4-6 games), plus 2024-25 lines for players who missed most of 2025-26 — from Basketball-Reference league per-game tables, fetched 2026-10-31.
- Current NBA teams from the 2026-27 table (players missing from that extract fall back to their latest 2025-26 team and are flagged).
- 2026 NBA Draft first round (order and school) — NBA.com.

**Simulated (so the season can be played forward)**
- The day-by-day NBA schedule (~3.7 games/team/week, no 3-in-3s).
- Individual box scores, generated from each player's real averages with internally consistent lines (PTS = 2·FGM + 3PM + FTM, makes ≤ attempts).
- The other managers (bots) for drafting, waiver adds and trade responses.

In production both simulated pieces are replaced by the real schedule and stat feeds; nothing else in the engine changes (see `docs/INTEGRATION.md`).

## Format features covered

- **Scoring:** H2H Each Category, H2H Most Categories, Rotisserie. Category presets: 8-cat (no TO), 9-cat, 10-cat (+DD), 11-cat (+DD, A/TO). Percentages compared at 3 decimals; TO is lower-is-better.
- **Rosters:** PG, SG, SF, PF, C, G, F, UTIL×3, BN×3, IR (standard 9-cat). Daily lineup lock, auto-start optimizer (bipartite matching so the most players with games get started).
- **Matchup view:** live category score (e.g. 6-3-0), FG/FT makes-attempts, games played/remaining, projected final, swing-category alerts, daily box scores, league scoreboard.
- **Players:** value rankings (volume-weighted z-scores), punt builder that re-ranks without punted cats, stat basis toggle (projection / 2026-27 / 2025-26), heat-mapped cells.
- **Trades:** category impact preview for every proposal, incoming offers with accept / counter / decline, future picks in dynasty.
- **Dynasty:** rosters carry over, rookie draft (linear, reverse standings), taxi squad (rookies + 2nd-year), tradeable 2027/2028 picks with ownership grid, age-adjusted dynasty values.
- **Season:** 20-week regular season, 4- or 6-team playoffs with byes (ties to the higher seed), champion crowned.
- **League chat** with system posts for trades, adds/drops and weekly results.

## Not done (Sleeper's side)

Accounts/auth, real-time multi-user sync, push notifications, waivers with priority/FAAB processing, the native mobile apps, real stat/injury/schedule feeds, commissioner tools, payments. This is a prototype of the game logic and UX, not a drop-in production service.
